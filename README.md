# STRIPS (Stanford Research Institute Problem Solver) — Explainer & Simulator

An interactive, educational web application and visual guide explaining **STRIPS**, the foundational classical AI planning algorithm developed in 1971 at SRI International for Shakey the Robot.

---

## 🚀 Features

- **Interactive Blocks World Simulator**: Set initial states, configure goals, and step through the planner’s thought process in real-time.
- **Visual State Transitions**: Real-time Add/Delete list diff inspection with color-coded predicate changes.
- **The Sussman Anomaly Explorer**: Interactive demonstration of goal clobbering and why naive linear planning fails.
- **Modern AI Lineage**: Connecting 1971 classical planning to modern LLM agents, PDDL, and ReAct tool use.
- **Sleek, Responsive UI**: Built with Next.js 14, React 18, Tailwind CSS, and Framer Motion.

---

## 🛠️ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
